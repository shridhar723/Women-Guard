This project details the development of a mobile application that shares a user's real-time location via SMS in emergency situations.

The app leverages Android's GPS and SMS functionalities to alert user-defined emergency contacts quickly and effectively.

🎯 Objectives
Ensure personal safety during emergencies

Provide quick access to communication tools

Deliver reliable location sharing across various Android devices

Offer a simple, user-friendly interface

This app is designed for broad usability and aims to be effective in real-life emergency scenarios.
